# Параметрический генератор мозаики (Parametric Mosaic Generator)

Одностраничное приложение (HTML/CSS/JS, без зависимостей) для сборки мозаики из
акриловых пластин 30 × 2.5 мм внутри любого силуэта.

- **Источник силуэта:** загрузка фото (трассировка контура) или 14 пресетов
- **Трассировка:** «Авто» (альфа-канал/порог яркости, работает офлайн) или
  «ИИ (Gemini / DeepSeek)» — распознавание главного объекта на фото через
  серверный прокси (`api/trace.js`), с автоматическим откатом на геометрический
  метод
- **Параметры:** плотность, зазор 3–8 мм, режимы заполнения (радиальный /
  горизонтальный / вертикальный / случайный), размер пластин — только 30 мм,
  ограничение количества деталей (зависит от формата: до 150 шт. для 40×40 см,
  до 120 шт. для 30×40 см), формат холста (30×40 / 40×40 см)
- **Экспорт:** SVG с точной геометрией (1 единица = 1 мм)
- **Языки:** русский, English, 中文

## ИИ-трассировка (Gemini / DeepSeek)

Браузер не обращается к провайдеру ИИ напрямую (домены Google заблокированы в
материковом Китае, у провайдеров могут быть региональные ограничения): клиент
отправляет уменьшенное JPEG-изображение на серверную функцию `/api/trace`, та
вызывает выбранный провайдер (`?provider` в запросе: `gemini` или `deepseek`) и
возвращает полигон внешнего контура главного объекта. Ключи хранятся только на
сервере.

- **Gemini** — регион функции `sin1` (Сингапур): Гонконг (`hkg1`) использовать
  нельзя — Gemini API не поддерживается из Гонконга. Модель по умолчанию
  `gemini-3.6-flash` (переопределяется через `GEMINI_MODEL`).
- **DeepSeek** — OpenAI-совместимый `/chat/completions` с vision-моделью, по
  умолчанию `deepseek-v4-flash-vision-exp` (переопределяется через
  `DEEPSEEK_MODEL`).

Настройка ключей (рекомендуется):

1. Vercel → Dashboard → ваш проект → Settings → Environment Variables.
2. Добавьте `GEMINI_API_KEY` и/или `DEEPSEEK_API_KEY` (по одному на провайдера).
3. Redeploy (Vercel сам предложит пересобрать после изменения переменных).

Без ключа соответствующий ИИ-режим мягко откатывается к геометрической
трассировке.

## Хостинг

- **Vercel (основной):** https://mosaic-art-rho.vercel.app/
  (деплой из репозитория GitHub `EldiiarZhaichybekov/mosaic-art`; чистый поддомен
  без суффикса, например `mosaic-art.vercel.app`, задаётся в Vercel →
  Dashboard → Project → Settings → Domains)
- GitHub Pages (запасной): https://eldiiarzhaichybekov.github.io/mosaic-art/
  (ИИ-режим на GitHub Pages недоступен — там нет серверной функции `/api/trace`)
- Локальная сборка: просто открыть `index.html` в браузере
  (ИИ-режим можно направить на развёрнутый прокси через `?traceApi=`:
  `index.html?traceApi=https://mosaic-art-rho.vercel.app/api/trace`)
