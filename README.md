# Параметрический генератор мозаики (Parametric Mosaic Generator)

> Актуальный путь загруженных фотографий: браузер → `/api/contour` → локальные
> OpenCV/NumPy → диагностический line-art. Старые описания клиентской трассировки
> ниже относятся к пресетам/историческому режиму. Фото требуют работающий сервер;
> открытие `index.html` через `file://` для них не подходит.
>
> Для локальной проверки: `pip install -r requirements.txt`, затем
> `flask --app api.contour run`. Основной сайт работает на Vercel.
> Геометрия, ограничения и проверки нового pipeline описаны в
> [CONTOUR_REPORT.md](CONTOUR_REPORT.md).

Одностраничное приложение (HTML/CSS/JS, без зависимостей) для сборки мозаики из
акриловых пластин 30 × 2.5 мм внутри любого силуэта.

- **Источник силуэта:** загрузка фото (геометрическая трассировка контура) или
  14 пресетов
- **Трассировка:** «Авто (геометрия)» — внешний контур по альфа-каналу или порогу
  яркости, с высокой детализацией; полностью офлайн, без внешних сервисов
- **Параметры:** плотность, зазор 3–8 мм, режимы заполнения (радиальный /
  горизонтальный / вертикальный / случайный), размер пластин — только 30 мм,
  ограничение количества деталей (зависит от формата: до 150 шт. для 40×40 см,
  до 120 шт. для 30×40 см), формат холста (30×40 / 40×40 см)
- **Экспорт:** SVG с точной геометрией (1 единица = 1 мм)
- **Языки:** русский, English, 中文

## Трассировка контура (геометрия)

Фото загружается в браузере, уменьшается и превращается в бинарную маску
(яркость или альфа-канал), из которой извлекается внешний контур главного
объекта. Полярность (тёмный объект на светлом фоне и наоборот) определяется
автоматически; ползунок «Порог» подстраивает детализацию в реальном времени.
Маска строится в высоком разрешении, поэтому тонкие элементы (крылья, лапы,
хвост) сохраняются в контуре. Всё считается на клиенте — без внешних API.
