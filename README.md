# Параметрический генератор мозаики (Parametric Mosaic Generator)

Одностраничное приложение (HTML/CSS/JS, без зависимостей) для сборки мозаики из
акриловых пластин 30 × 2.5 мм и 20 × 2.5 мм внутри любого силуэта.

- **Источник силуэта:** загрузка фото (трассировка контура) или 14 пресетов
- **Параметры:** плотность, зазор 3–8 мм, режимы заполнения (радиальный /
  горизонтальный / вертикальный / случайный), размер пластин (30 / 20 / микс),
  ограничение количества деталей, формат холста (30×30 … 40×50 см)
- **Экспорт:** SVG с точной геометрией (1 единица = 1 мм)
- **Языки:** русский, English, 中文

## Хостинг

- GitHub Pages: https://eldiiarzhaichybekov.github.io/mosaic-art/

  в этой папке; нужный поддомен (например `mosaic-art.vercel.app`) задаётся в
  Vercel → Dashboard → Project → Settings → Domains.
